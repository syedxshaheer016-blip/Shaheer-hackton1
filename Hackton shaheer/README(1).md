# first-hackton: Smart Bus Ticket Booking & Reservation System

The project is in the [`smart-bus-hackathon/`](smart-bus-hackathon/) folder.

```bash
cd smart-bus-hackathon
python3 main.py          # run the program (built-in Python only)
python3 -m unittest -v   # run the automated tests
```

See [`smart-bus-hackathon/README.md`](smart-bus-hackathon/README.md) for full instructions.
