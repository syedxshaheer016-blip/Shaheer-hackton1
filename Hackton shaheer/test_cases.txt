EXTRA CHECKS (test_core.py and test_main.py, all PASS)
- All 5 starter routes keep their original fares (1200, 2000, 800, 5000, 1500).
- Search is case-insensitive; route ID search returns exactly one route; blank search returns nothing.
- Rejected without any change: blank/space-only name, age "abc", 0, -5, "24.5", 200, True,
  unknown route R999, seats 0, -2, "two", 2.9, and 41 (more than capacity).
- 10 bookings in a row get 10 different IDs; a cancelled ID (B1001) is never reused.
- Overbooking after a partial booking is rejected (25 booked, 6 more requested, 5 left).
- Unknown booking ID cannot be cancelled; cancelled bookings stay in history.
- Report with 3 bookings (1 cancelled): revenue 47,400 and seats 33 count Confirmed only.
- Per-route report and schedule grouping give the expected numbers.
- Status labels change Available -> Partially Booked -> Fully Booked correctly.
- If input ends suddenly (no option 8), the program closes politely with no error.
